# Artist Tools 1.4.6 — сценарий видео

Примерно 7 минут 30 секунд. Основной показ: Road, Wires и Measure. Сценарий сверен с текущими исходниками; перед записью нужно пройти действия в редакторе.

## Подготовка

- Сцена offroad: рельеф, камни, свободное место для дороги. Снимай на копии мира.
- Материал дороги для Mesh и отдельный материал для Decal; секция бордюра или забора для Bent Mesh.
- Столбы с dummy-узлами `wire_1`, `wire_2`, `wire_3`, изолятор и меш цепи. Для Connect Poles заранее поставь два столба с точками крепления.
- Материал с прозрачностью для Cross и Ribbon. Для показа ветра нужен материал, использующий вертекс-колор; сами маски не включают анимацию.
- Подготовь дверь для измерения и сравнения с фигурой человека. Закрой блоки горячих клавиш, выставь удобный размер панели.

## 0:00–0:20 — Вступление

**Кадр:** общий план готовой сцены, затем вкладки Road → Wires → Measure.

**Озвучка:** «Сегодня покажу три инструмента Artist Tools: дороги по кривой, провода между столбами и измерения прямо во вьюпорте. Всё внутри редактора UNIGINE».

## 0:20–0:50 — Road: рисуем кривую

**Действия:** New Road, добавление точек по земле в режиме Add Points. Ctrl + клик — угловая точка. Переместить точку, выделить две соседние и нажать Subdivide.

**Озвучка:** «Намечаем дорогу кликами по земле. Ctrl с кликом добавляет острый угол. Точки можно двигать по поверхности, а Subdivide добавляет точку между соседними».

## 0:50–1:20 — Ширина и мост

**Действия:** изменить Width, показать Strips Across и скругление внутреннего края. Изменить ширину одной точки. Поднять точку с режимом On Curve над рельефом.

**Озвучка:** «Ширина задаётся для всей дороги и отдельно в каждой точке. Можно сделать сужение, расширение или приподнять участок над землёй — например, для съезда на мост».

## 1:20–1:35 — Фильтр поверхности

**Действия:** в Lay On оставить Terrain; показать участок под камнями.

**Озвучка:** «Lay On выбирает поверхности, на которые ложится дорога. Здесь оставляю только рельеф, чтобы камни не поднимали сетку».

## 1:35–2:00 — Меш, декаль и маски

**Действия:** переключить Mesh → Decal, назначая подходящий материал для каждого режима. Изменить поворот UV. Показать превью вертекс-колора.

**Озвучка:** «Дорогу можно сделать мешем или декалью. Материал перетаскиваем из Asset Browser; для декали нужен decal-материал. Маски в вертекс-колоре можно использовать для смешивания в своём шейдере».

## 2:00–2:40 — Bent Mesh

**Действия:** включить Bent Mesh, добавить секции через Add Selected Assets. Показать Pattern, Start, End и повтор секции. Изогнуть кривую; показать настройку Mesh Angle.

**Озвучка:** «Вместо плоской дороги можно согнуть вдоль кривой готовые меши: бордюр, забор или трубу. Повторяющиеся секции идут по всей длине, начало и конец задаются отдельно. Плотность разбиения на изгибах регулируется».

## 2:40–3:00 — Сохранение результата

**Действия:** Generate, показать файлы. Назначить материал одному куску, немного сдвинуть точку и повторить Generate. Показать Ctrl+Z.

**Озвучка:** «Generate сохраняет меши в проект. Материал, назначенный куску, сохраняется при повторной генерации. Изменения в сцене можно отменить».

**Примечание для записи:** не говорить «всё откатывается»: Undo не возвращает уже записанные файлы на диске. Не обещать сохранение произвольных ручных правок геометрии.

## 3:00–3:40 — Wires: линия столбов

**Действия:** New Line, Add Points по земле. Добавить ассет столба. Сравнить At Points и Every с расстоянием 30. Показать отдельный ассет с ролью Corner.

**Озвучка:** «Столбы можно поставить в точках линии или через заданное расстояние. Для поворотов, начала и конца есть отдельные роли».

## 3:40–4:00 — Крепления

**Действия:** показать dummy-узлы wire_1…wire_3 в ассете и точки крепления во вьюпорте.

**Озвучка:** «Точки крепления задаются пустышками внутри столба: wire_1, wire_2 и так далее. Провода соединяют крепления с одинаковыми номерами».

## 4:00–4:30 — Провисание

**Действия:** Like Real Wires, изменить Sag и Random. У выбранной точки задать Sag × 2. Увеличить расстояние между столбами.

**Озвучка:** «В режиме Like Real Wires длинные пролёты провисают сильнее. Random добавляет разброс, не уменьшая заданное провисание. Пролёт от выбранной точки к следующей можно настроить отдельно».

## 4:30–4:55 — Наклон и изоляторы

**Действия:** повернуть точку манипулятором, показать наклон столба. Добавить ассет с ролью Insulator.

**Озвучка:** «Поворотом точки можно сделать покосившийся столб. Изоляторы расставляются на креплениях автоматически».

## 4:55–5:20 — Геометрия провода

**Действия:** Make Of: Cross → Ribbon → Tube → Mesh. На ленте показать Twist; у одного пролёта изменить Twist +.

**Озвучка:** «Для провода есть крест из полосок, лента, трубка или собственный меш — например, цепь. Закрутка настраивается для всей линии и отдельно для пролётов».

## 5:20–5:45 — Земля и готовые столбы

**Действия:** увеличить провисание, включить Above Ground. Коротко показать маски вертекс-колора. Connect Poles → Add Poles, кликнуть по заранее подготовленным столбам. Generate.

**Озвучка:** «Above Ground удерживает кабель над поверхностями из фильтра Lay On. Вертекс-колор содержит данные для шейдера ветра. А Connect Poles соединяет столбы, которые уже стоят в сцене».

**Монтаж:** эти примеры лучше снять отдельными короткими дублями. Если темп слишком быстрый, убрать показ масок; LOD и разбиение на куски оставить для отдельного ролика.

## 5:45–6:15 — Measure: длина и уклон

**Действия:** Ruler, два клика на разных высотах. Показать длину, горизонтальную проекцию, разницу высот и уклон.

**Озвучка:** «Два клика — и видны длина, перепад высоты и уклон. Измерения отображаются во вьюпорте, без добавления объектов в мир».

## 6:15–6:40 — Точное попадание

**Действия:** нажать и отпустить Ctrl над вьюпортом для переключения привязки к вершинам. Показать Snap To Points, затем Z и Shift + Z. Включить лупу; при постановке точки удерживать Shift.

**Озвучка:** «Можно привязаться к вершине или к точке другого измерения. X, Y, Z фиксируют ось, с Shift — плоскость. Лупа и замедление курсора помогают точно выбрать место».

**Примечание:** Ctrl переключает режим по нажатию и отпусканию; его не нужно держать. Замедление Shift действует при постановке и перетаскивании точек.

## 6:40–6:55 — Угол

**Действия:** Angle, три клика по заранее выбранному углу постройки.

**Озвучка:** «Для проверки угла выбираем Angle и задаём две стороны тремя точками».

## 6:55–7:15 — Масштаб

**Действия:** Person, поставить фигуру у двери. Навести курсор на фигуру и колесом изменить рост.

**Озвучка:** «Фигура человека помогает оценить масштаб. Меняем рост колесом и сразу сравниваем его с дверью, забором или столбом».

## 7:15–7:30 — Финал

**Кадр:** готовая дорога, линия проводов, фигура человека. Коротко показать остальные вкладки и версию внизу окна.

**Озвучка:** «Это Road, Wires и Measure в Artist Tools. В том же окне — Object Placer, Path Placer, распаковка клаттеров и Baker для запекания текстур. Ссылки в описании».
